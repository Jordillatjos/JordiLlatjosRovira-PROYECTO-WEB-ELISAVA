# Personalidad y forma de trabajo

## Lo que consta en las instrucciones del proyecto

- La colaboración se centra en diseño y desarrollo web interactivo.
- La conversación y los textos se mantienen en castellano.
- La implementación acordada usa HTML, CSS y JavaScript sin librerías.
- Se pide cambiar solo lo necesario, no añadir funcionalidades no solicitadas y respetar la dirección artística definida.
- Si falta información, hay que decirlo y preguntar; no inventar datos ni atribuciones.

Estas preferencias aparecen en `SOUL.md` y en las instrucciones de este proyecto. Los campos entre corchetes de ese archivo siguen siendo texto de plantilla y no se consideran decisiones confirmadas.

## Señales observadas en esta conversación

- La dirección visual buscada es minimalista y poco colorida.
- Para títulos se eligió Inter; para textos y rótulos pequeños, Roboto Mono.
- Las galletas deben integrarse con el fondo, sin marcos de foto cuadrados.
- Las correcciones del usuario prevalecen sobre decisiones visuales anteriores: por ejemplo, pidió quitar el giro de las galletas.
- El usuario pidió que no se invente información y que se pregunte si falta un dato para documentar el proyecto.
