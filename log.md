# Registro de decisiones y cambios

Las iteraciones anteriores no tienen una fecha individual verificable en el historial visible. Se registran por orden, sin asignarles fechas no confirmadas.

1. Se partió de los archivos HTML, CSS y JavaScript del proyecto. El usuario pidió una portada con seis galletas y un aviso de cookies.
2. Se implementó el aviso inicial, la galería interactiva y una explicación de cada categoría en una pestaña nueva.
3. Se generó una primera hoja de seis galletas; el usuario pidió sustituir las dos galletas centrales por variedades más parecidas al resto. Se creó después una imagen con seis galletas redondas.
4. El usuario pidió eliminar los recuadros de las imágenes, igualar el fondo al de la web y aplicar el zoom solo a cada galleta. Se añadió una imagen de galletas recortadas con fondo transparente.
5. Se ajustaron las filas y los rótulos tras las capturas del usuario para evitar que categorías, números y nombres se solaparan.
6. El usuario pidió acumular las palabras de personalización hasta llenar la pantalla y que entraran desde fuera del marco sin tirones. Se modificó la animación para iniciar las palabras fuera del borde y reducir el trabajo por fotograma.
7. El usuario pidió tipografía Inter para títulos y Roboto Mono para textos pequeños, y un título que se escribe y se borra en bucle.
8. El usuario pidió retirar el giro de las galletas. El estado actual conserva el zoom, sin giro.
9. El 24/11/2026 se prepararon estas notas y las dos fichas de scroll a partir del contenido actual y de las instrucciones del proyecto.
