# Datos personales como material para publicidad

Web interactiva que explica, mediante seis galletas, algunas formas en que los datos de navegación pueden utilizarse en publicidad digital.

## Abrir la web

Abre `index.html` en un navegador. No requiere instalación ni compilación.

## Recorrido

- Al entrar aparece el aviso de cookies. «Aceptar cookies» muestra la web; «Personalizar cookies» abre la pantalla de palabras que caen y se acumulan, con una única opción para aceptarlas.
- La portada introduce el tema y el título se escribe y borra en un bucle.
- La galería contiene seis galletas interactivas con su categoría indicada en la tarjeta. Al pasar el cursor se amplía la galleta; al hacer clic se abre una explicación en otra pestaña.

## Archivos principales

- `index.html`: página principal y aviso inicial.
- `style.css`: estilos, distribución y animaciones.
- `script.js`: galería, explicaciones y comportamientos interactivos.
- `cookies-cutouts.png`: imagen de las seis galletas, con fondo transparente y ruta relativa desde `style.css`.
- `personalidad.md`, `contexto.md`, `criterio.md`, `log.md`: dirección del proyecto y registro.
- `fichas/`: documentación de las dos pantallas verticales.

La tipografía usa Inter para títulos y Roboto Mono para textos pequeños. Las fuentes se cargan desde Google Fonts; si no hay conexión, se usan fuentes de reserva.

## Alcance de los datos

Los ejemplos concretos de la web son ficticios, tal como indica el encargo. El proyecto parte de una exportación personal de TikTok mencionada en `contexto.md`, pero la web actual no representa esos datos personales como visualización.
